## 🎯 Step-by-Step Fix

### Step 1: Choose Your Page
Decide which page you want to use:
- Option A: **Crauto** 
- Option B: **Automatter**

### Step 2: Connect Instagram to Your Page

1. Go to your Facebook Page:
   - For Crauto: https://www.facebook.com/715412561666556
   - For Automatter: https://www.facebook.com/869029502955016

2. Click **Settings** (left sidebar)

3. Click **Instagram** (or **Linked Accounts**)

4. Click **Connect Account**

5. **IMPORTANT**: Make sure your Instagram account is:
   - ✅ A **Business Account** or **Creator Account**
   - ✅ Not a personal account (won't work!)

#### How to Convert Instagram to Business Account:
1. Open Instagram app
2. Go to Settings → Account
3. Click "Switch to Professional Account"
4. Choose "Business" or "Creator"
5. Complete the setup

### Step 3: Get New Access Token

1. Go to: https://developers.facebook.com/tools/explorer/

2. Click **Select an App** → Choose your app (or create one)

3. Click **Generate Access Token**

4. Select these permissions (IMPORTANT - must have ALL):
   - ✅ `pages_show_list`
   - ✅ `pages_read_engagement`
   - ✅ `instagram_basic`
   - ✅ `instagram_content_publish`
   - ✅ `business_management`

5. Click **Generate Token**

6. **Copy the generated token** (starts with EAA...)

### Step 4: Run the Token Generator Again

1. Update `.env` with your NEW user token:
   ```
   FACEBOOK_ACCESS_TOKEN=<paste_your_new_token_here>
   ```

2. Update the page ID:
   ```
   # If using Crauto:
   FACEBOOK_PAGE_ID=715412561666556
   
   # OR if using Automatter:
   FACEBOOK_PAGE_ID=869029502955016
   ```

3. Run the script:
   ```bash
   python get_page_token.py
   ```

4. The script will:
   - ✅ Find your page
   - ✅ Get the Instagram Business Account ID
   - ✅ Generate a **PAGE ACCESS TOKEN** (not user token!)
   - ✅ Test if posting will work

### Step 5: Update .env with Results

The script will output something like:
```
FACEBOOK_ACCESS_TOKEN=EAAJOhil1fDs... (long page token)
INSTAGRAM_BUSINESS_ACCOUNT_ID=17841477058310249
FACEBOOK_PAGE_ID=715412561666556
```

**Copy these EXACT values** to your `.env` file!

## ⚠️ Common Mistakes

### ❌ DON'T DO THIS:
- Using a User Access Token (won't work for posting)
- Using a personal Instagram account (must be Business/Creator)
- Forgetting to connect Instagram to Facebook Page
- Missing permissions when generating token

### ✅ DO THIS:
- Use the **PAGE ACCESS TOKEN** (generated by our script)
- Use an **Instagram Business Account**
- Connect Instagram to your Facebook Page FIRST
- Request ALL required permissions

## 🆘 Still Not Working?

### Error: "Object does not exist" (Code 100, Subcode 33)
- Instagram account is NOT a Business account
- Instagram not properly connected to Facebook Page
- Wrong Instagram Business Account ID

### Error: "Missing permissions"
- Regenerate token with ALL required permissions
- Make sure you're using the PAGE token, not user token

### Error: "Page not found"
- Update FACEBOOK_PAGE_ID to one of your actual pages
- Make sure you're an admin of that page
